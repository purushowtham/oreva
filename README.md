# ORÉVA Studio — Prototype

A first-pass Next.js prototype based on the supplied ORÉVA Studio build guide.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Replace placeholders

The prototype currently uses CSS art-direction in place of the final photography and GLB/GLTF assets. Replace the marked image areas and 3D shapes with the supplied ORÉVA photos/models when available.

## Main structure

- Cinematic hero: Spaces. Stories. Desire.
- Scroll-oriented 3D gallery prototype
- ORÉVA Cabinet services
- Editorial selected work
- ORÉVA Method
- Studio
- Material / Mood journal
- Contact

The visual system follows the supplied guide: ivory/champagne/taupe/brown/bronze palette, Cormorant Garamond + Montserrat, large negative space, tactile materials and restrained motion.
